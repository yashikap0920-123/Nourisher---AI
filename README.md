# NourishHer - AI Nutrition for Underprivileged Women

NourishHer is an AI-powered app that creates affordable, personalized nutrition plans for women under Rs 50-100.

## Problem
Many women can't afford expensive healthy diets and don't know low-cost alternatives.

## Solution
- User enters Budget, Health Goal (like Anemia, Low Energy) & Available Ingredients
- AI calculates Protein, Iron, Calcium, Calories
- Suggests Smart Low-Cost Swaps: e.g., Almond -> Roasted Chana, Spinach -> Moringa Leaves
- Generates Full Day Diet Chart (Breakfast, Lunch, Dinner)

## Tech Stack
- Python
- Streamlit
- Pandas

## How to Run
pip install -r requirements.txt
streamlit run app.py
